1 — What Is a Domain & How It Works

A domain name like ssss.org is a human-readable address that maps to a server's IP address (e.g. 75.2.60.5). Without a domain, visitors would need to type a raw IP number — which nobody does.

The Domain Name System (DNS) is a global phone book. When someone types www.ssss.org, their browser asks a DNS server: "What IP is this?" DNS answers, and the browser connects to that IP.

A registrar is an accredited company (Namecheap, Porkbun, GoDaddy) authorised to sell domain registrations on behalf of ICANN — the global authority that oversees all domain names.

.org is the TLD historically used by non-profit organisations and societies — perfect for the Soil Science Society of Syria. 
ICANN (global authority)
  └─► Public Interest Registry (manages .org TLD)
        └─► Porkbun / Namecheap (registrars — sell to you)
              └─► YOU (domain owner / registrant)
                    └─► DNS records → point to Netlify + Railway

7 — What You Own After Purchase

What "owning a domain" means: You have the exclusive right to use it for the period you paid for. After that, renew or anyone can take it.

What you can do: Point it at any server, create email @ssss.org, transfer it to another registrar, sell it.

What you cannot do: Own it forever without renewal. Owning ssss.org does NOT give you ssss.com automatically.

9 — Point the Domain at Your Hosting (DNS)

What is DNS? DNS records tell the internet which server to send visitors to when they type your domain.

Record types you need:
• A record — maps domain → IPv4 address (e.g. ssss.org → 75.2.60.5)
• CNAME record — maps domain → another domain (e.g. www.ssss.org → your-site.netlify.app)
• MX record — for email routing (only needed when setting up email @ssss.org)
• TXT record — for domain verification by Netlify, Google, etc.

DNS propagation: After adding records, it takes 5 min – 48 hours to propagate worldwide. During this time some visitors may see the old address. This is normal.

11 — Connect Domain to Railway (Backend API)

7

Use Netlify proxy (recommended — free, no extra DNS)

Add to netlify.toml so ssss.org/api/* proxies silently to Railway:

[[redirects]]
  from   = "/api/*"
  to     = "https://ssssy-websit-production.up.railway.app/api/:splat"
  status = 200
  force  = true

[[redirects]]
  from   = "/storage/*"
  to     = "https://ssssy-websit-production.up.railway.app/storage/:splat"
  status = 200
  force  = true

Then in Netlify Environment Variables set:

NEXT_PUBLIC_API_URL = https://ssss.org/api
The browser calls ssss.org/api/.... Netlify's servers forward that to Railway and return the response. The user never sees the Railway URL. No CORS issues, no extra DNS records, no extra cost.

13 — Renewal — Never Lose Your Domain

If you forget to renew, the domain enters a grace period (30 days, normal price), then a redemption period (30–60 days, costs $100–300 to recover), then it is released for anyone to buy.
  • Enable Auto-Renew — most important step
  • Keep payment method current — update card before it expires
  • Keep registrar email active — renewal reminders come 90/60/30/15/7 days before expiry
  • Register for 2–3 years — fewer renewal events to worry about
  • Set a calendar reminder — 60 days before expiry as a backup
