2. قاعدة البيانات — PostgreSQL مطلوب

⚠️ استخدم Railway Reference Syntax — Railway يحلّها تلقائياً من PostgreSQL service المرتبط
المتغيرالقيمةالوصف
SPRING_DATASOURCE_URLjdbc:postgresql://${{Postgres.PGHOST}}:${{Postgres.PGPORT}}/${{Postgres.PGDATABASE}}رابط قاعدة البيانات
SPRING_DATASOURCE_USERNAME${{Postgres.PGUSER}}اسم المستخدم
SPRING_DATASOURCE_PASSWORD${{Postgres.PGPASSWORD}}كلمة المرور
💡 إذا كنت تستخدم Neon بدلاً من Railway PostgreSQL، ضع connection string مباشرة:
SPRING_DATASOURCE_URL=jdbc:postgresql://ep-xxx.neon.tech/neondb?sslmode=require
SPRING_DATASOURCE_USERNAME=neondb_owner
SPRING_DATASOURCE_PASSWORD=your_neon_password

4. JWT Secret مطلوب — حرج

المتغيرالقيمةالوصف
JWT_SECRET← أنشئه بالأمر أدناه256-bit سر لتوقيع الـ JWT tokens — لا تشاركه أبداً
🔑 أنشئ JWT_SECRET بهذا الأمر في PowerShell:
-join ((1..32) | ForEach-Object { '{0:x2}' -f (Get-Random -Max 256) })
أو في Linux: openssl rand -hex 32
