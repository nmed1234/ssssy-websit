1 · Current State Deep Analysis

What the Screenshots Show

From the 5 attached screenshots (homepage news section, /news listing, /admin/content list, /admin/content/new, /admin/content/[id] edit), the following is clear:

Public: News Listing Page (/news)

❌ No featured image renders — only a Newspaper icon placeholder (no actual content images loaded)
❌ Cards are generic grey boxes with no visual hierarchy or brand character
❌ The category filter tabs (All / Announcements / Articles) are purely visual — they do NOT actually filter the API results, only client-side already-fetched data
❌ No bilingual awareness: cards always show English title even when the user is in Arabic mode
❌ Date is formatted only in English even in Arabic locale
❌ No reading time shown on the listing card
❌ No content type badge (News vs Article vs Announcement) on card
❌ Pagination only shows "Previous / Page X of Y / Next" — no numbered pages

Public: News Detail Page (/news/[slug])

❌ Article body text direction is always LTR — Arabic content renders incorrectly
❌ "Back to News" always in English regardless of language
❌ No related articles section at bottom
❌ No table of contents for long articles
❌ No print / copy-link buttons

Admin: Content List (/admin/content)

❌ Title column shows only Arabic title — missing fallback logic showing EN when AR is empty (and vice versa)
❌ Clicking a title navigates to edit page but the link is hard to distinguish (no visual cue like external/open icon)
❌ No "Preview on site" link from the list
❌ No type filter (can't filter by ARTICLE / NEWS / PUBLICATION)
❌ Pagination hardcoded to size: 50 — no server-side pagination
❌ Status badges have only 3 colour variants (green/yellow/gray) — IN_REVIEW, APPROVED, REJECTED, SCHEDULED all render gray
❌ No statistics bar (how many published / draft / review etc.)
❌ No featured image thumbnail in the row
❌ View count column missing

Admin: New / Edit Content Form

❌ Featured image upload missing — only an OG Image URL text field; no actual media picker
❌ Slug is auto-generated from Arabic title but produces Arabic characters in slug (bad for SEO) — needs transliteration
❌ The excerpt field is a plain <textarea> with no character counter
❌ Scheduled publish date field missing in the form
❌ No "Save as Draft" vs "Save & Submit" split button
❌ Content body and excerpt fields have no language toggle (editing Arabic body vs English body is not split)
❌ Tags field shows no visual selected count or "clear all" option
❌ Form has no unsaved-changes warning on navigation away
❌ SEO section has no preview of how the page will look in Google search results

3 · Detailed Design Decisions

A · Public News Page — Visual Redesign

Card Layout

Current (bad)
Fixed 192px grey box with icon fallback · title always EN · no badge · no reading time
Enhanced
Gradient placeholder with soil palette when no image · bilingual title (AR when locale=ar, EN otherwise) · content type badge (color-coded) · reading time from word count · date in locale format (ar-SY or en-US)

Category Tabs

Current tabs only filter client-side the first 9 items. Enhancement: map tab to API content type param, refetch on change. Add animated underline indicator, count badge per category.

Bilingual Article Detail

Add dir="auto" on the prose container and choose titleAr vs titleEn based on useLanguage() direction. Format date with ar-SY locale when Arabic. "Back to News" / "العودة للأخبار" based on language.

Related Articles

Fetch same content type filtered by same category via serverGetContentByType, exclude current slug, show 3 in a grid below the article. SSR with revalidate:300.

B · Admin Content List — Power Upgrades

Statistics Bar

Row of stat cards above the table: Total · Published · Draft · In Review · Archived. Each is a clickable filter shortcut. Derived from the already-fetched data client-side.

Full Status Colour Palette

Type Filter Dropdown

Add a second filter next to the status filter: All Types / ARTICLE / NEWS / PUBLICATION / PAGE. Applies client-side. Also show type badge with proper translated label.

Thumbnail Column

32×32 px rounded thumbnail before the title link. Shows featured image or a soil-coloured initial square.

Preview Link

Each row: external link icon → /news/[slug] or /content/[type]/[slug] in a new tab. Visible on row hover only to reduce clutter.

View Count Column

Add viewCount column (sortable). Shows formatted number with an eye icon.

C · Admin New / Edit Form — Advanced Options

Featured Image Upload (Media Picker)

Replace the plain ogImageUrl text field for featured image with a media picker button. Opens a modal with the existing MediaLibraryModal component (already in codebase). Sets featuredImage field. Show thumbnail preview below.

Bilingual Body Tabs

The RichTextEditor is a single-language field. Add a Language Tabs switcher above the body: AR | EN. Each tab has its own body value (body for Arabic, bodyEn for English). On public render, choose based on locale.

⚠️ Note: The backend ContentItem currently only has one body field. For Phase 1 of this enhancement we will keep one body but add the lang toggle inside the editor so editors can write in either language and see the direction change. True dual-body requires a backend migration — schedule as Phase 2.

Slug Auto-generation with Transliteration

Current code: e.target.value.replace(/\s+/g, "-").toLowerCase() — this leaves Arabic letters in the slug. Fix: add a simple Arabic-to-Latin transliteration function that converts common Arabic characters to phonetic equivalents, or simply strip non-ASCII and use the English title as slug source when available.

Scheduled Publish Date

Add a datetime-local input for scheduledAt field. Only visible / active when content type allows scheduling. When set, the "Save" button changes to "Schedule".

Excerpt Character Counter

Add a X / 300 characters counter below the excerpt textarea. Turns red above 300.

Split Action Button

Replace the single "Save" button with a split button: primary = "Save as Draft" · dropdown arrow → "Save & Submit for Review". On edit, primary = "Save" · dropdown → "Save & Publish" (if APPROVED).

Unsaved Changes Guard

Track isDirty boolean (form !== original data). On navigate-away (useBeforeUnload + router.beforePopState): show confirm dialog "You have unsaved changes. Leave anyway?"

SEO Google Preview

In the SEO tab, below the meta fields, add a live-updating visual preview of how the page appears as a Google search result: site domain + URL · blue title · green URL · grey description. Updates as user types meta title/description.
