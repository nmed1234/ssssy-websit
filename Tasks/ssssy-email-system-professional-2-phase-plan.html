Your Question: After Deployment — admin@ssssyria.org and info@ssssyria.org

Q: After deployment, do I automatically have admin@ssssyria.org and info@ssssyria.org? How do I access them?

Short answer: NOT automatically — these are two different kinds of addresses that require two different setups.

admin@ssssyria.org — Website Admin Login

This is a user account in the database (seeded in V1__users_roles.sql). It is the website login only.

  • Username: admin, Email: admin@ssssyria.org, Password: admin123
  • You access this at https://ssssyria.org/auth/login → goes to /admin dashboard
  • This is NOT a real email inbox — it's just the email field on your website user account
  • You cannot receive emails sent to admin@ssssyria.org unless you set up Mailcow (Phase 2)

info@ssssyria.org — Contact/Info Email

This address appears in footer and contact settings but it is just a display string stored in site settings. It is not a real inbox either.

  • Right now: shows as contact email on the public website
  • Visitors who email it: nothing happens (no server receives it)
  • To receive emails at info@ssssyria.org: you need Mailcow (Phase 2) OR simply forward DNS MX to Gmail/Google Workspace

How to receive emails at admin@ and info@ WITHOUT Mailcow (Phase 1 workaround):

  • Option A — Google Workspace: Add your domain to Google Workspace ($6/mo), set MX records → you get real Gmail at admin@ssssyria.org
  • Option B — Zoho Mail Free: Zoho Mail free tier supports 5 users, real IMAP inbox — set MX records to Zoho, get admin@ and info@ for free
  • Option C — Mailcow (Phase 2): Full self-hosted solution on your own VPS — covered below
Recommendation: In Phase 1, use Zoho Mail free for admin@ssssyria.org and info@ssssyria.org. It's free, takes 15 minutes, and you access it via webmail at mail.zoho.com or Outlook/iPhone. Then Phase 2 (Mailcow) handles member email accounts like ahmad.hassan@ssssyria.org.

Phase 2 — Implementation Tasks

1
Deploy Mailcow on Hetzner CX22 VPS Infrastructure
Hetzner CX22: 2 vCPU, 4 GB RAM, 40 GB SSD — ~$4-6/mo. Mailcow minimum requirement: 6 GB RAM (use CX32 at ~$8/mo for safety). 
git clone https://github.com/mailcow/mailcow-dockerized
cd mailcow-dockerized
./generate_config.sh  # MAILCOW_HOSTNAME=mail.ssssyria.org
docker compose pull && docker compose up -d
2
Configure DNS Records DNS
Add these records to your domain registrar (Namecheap, Cloudflare, etc.): 
Type    Name                  Value
──────────────────────────────────────────────────────
A       mail                  [Hetzner VPS IP]
MX      @                     mail.ssssyria.org  (Priority 10)
TXT     @                     v=spf1 mx -all
TXT     dkim._domainkey       [value from Mailcow admin panel]
TXT     _dmarc                v=DMARC1; p=quarantine; rua=mailto:admin@ssssyria.org
CNAME   autoconfig            mail.ssssyria.org   (auto-config for Outlook/Thunderbird)
CNAME   autodiscover          mail.ssssyria.org   (auto-config for Outlook)
3
Create admin@ and info@ mailboxes in Mailcow UI Manual Setup
Go to https://mail.ssssyria.org/admin → Mailboxes → Add Mailbox. Create: admin@ssssyria.org and info@ssssyria.org. Access via: https://mail.ssssyria.org (SOGo webmail) or configure in Outlook/iPhone using IMAP settings.

Config: MAILCOW_API_URL, MAILCOW_API_KEY in environment variables.
5
Integrate Mailcow into EmailAccountService.provisionAccount() Backend
After saving the DB record, call Mailcow API: 
// After emailAccountRepository.save(account):
if (mailcowEnabled) {
    mailcowApiService.createMailbox(
        emailAddress,
        tempPassword,          // same password as DB
        defaultQuota / 1024 / 1024  // convert bytes → MB
    );
}
Use a feature flag MAILCOW_ENABLED=true so Phase 1 still works without Mailcow.
6
Update IMAP Sync to use Mailcow server Backend
Change environment variables: 
SSSSY_EMAIL_IMAP_HOST=mail.ssssyria.org
SSSSY_EMAIL_IMAP_PORT=993
SSSSY_EMAIL_IMAP_SSL=true
EmailSyncService will now poll the real mailboxes every 5 minutes and copy incoming external emails to the PostgreSQL DB for the website inbox UI.
7
Update Outgoing SMTP to use Mailcow Backend
For member-to-external emails, switch from Brevo to Mailcow SMTP: 
SPRING_MAIL_HOST=mail.ssssyria.org
SPRING_MAIL_PORT=587
SPRING_MAIL_USERNAME=admin@ssssyria.org  # relay account
SPRING_MAIL_PASSWORD=[mailcow password]
Keep Brevo for transactional emails (password reset, notifications) separately.
8
Migrate existing members to Mailcow mailboxes Migration
Write a one-time migration endpoint or Spring Boot @PostConstruct bean that:
  • Fetches all existing email_accounts where Mailcow account does not yet exist
  • Calls mailcowApiService.createMailbox() for each
  • Generates new temp password, stores in DB, sends email to member with their IMAP credentials

Add IMAP Credentials Display on Email Settings Page Frontend
Show in /email/settings — "Configure in Outlook/iPhone":

10
Sync Quota Between Mailcow and DB Backend
Add a daily cron task that calls mailcowApiService.getQuotaUsed(address) for each account and updates email_accounts.used_bytes in DB. This keeps the website quota display accurate when mail arrives from outside (not via internal delivery).
11
Enable ClamAV Antivirus Security
Mailcow bundles ClamAV. After confirming it runs on the VPS: 
CLAMAV_ENABLED=true
CLAMAV_HOST=mail.ssssyria.org
CLAMAV_PORT=3310
EmailAttachmentService already has ClamAV scanning logic — just needs the server address.

How to Access admin@ and info@ — Step by Step

Option A: Zoho Mail Free (Recommended for Phase 1)

  1. Go to mail.zoho.com → "Add my domain" → enter ssssyria.org
  2. Zoho will give you TXT record to verify domain ownership — add it in your domain registrar DNS
  3. Add MX records: mx.zoho.com (priority 10), mx2.zoho.com (priority 20)
  4. Create accounts: admin@ssssyria.org and info@ssssyria.org
  5. Access via browser: https://mail.zoho.com — login with your Zoho account
  6. Or configure in Outlook/iPhone: IMAP imap.zoho.com:993, SMTP smtp.zoho.com:465
Cost: $0/month. 5 mailboxes. 5 GB per mailbox. No credit card needed.

Option B: Mailcow (Phase 2 — Self-hosted)

  1. Deploy Mailcow on Hetzner VPS (as described in Phase 2 Step 1)
  2. Open https://mail.ssssyria.org/admin — Mailcow admin panel
  3. Go to Mailboxes → Add Mailbox → create admin@ssssyria.org and info@ssssyria.org
  4. Access webmail at https://mail.ssssyria.org (SOGo)
  5. Or use Outlook: IMAP mail.ssssyria.org:993, SMTP mail.ssssyria.org:587
Cost: ~$11/mo for VPS. All member @ssssyria.org addresses also become real. Best long-term solution.
